# Lucas Romero — Portfolio

Personal portfolio of **Lucas Romero**, AI/ML Engineer & Full-Stack Developer.

Live: [lucasromero.dev](https://lucasromero.dev)

Static single-page site (plain HTML/CSS/JS, no build step). Open `index.html`
in a browser to view it locally, or deploy it as-is on Vercel.

- `index.html` — the page (styles inline), `main.js` — its scripts.
- `404.html` — custom not-found page (served automatically by Vercel).
- `robots.txt`, `sitemap.xml`, `llms.txt` — crawler and LLM files.
- `og-image.png` — 1200×630 social preview image.
- `vercel.json` — security headers (CSP, HSTS, etc.).
